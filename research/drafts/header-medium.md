# Fighter strategies

How each Unmatched fighter wins, how they lose, the cards that matter and practical tips, with links to the guides they come from.

Fighters are in the same order as the site. Each entry starts with an `<!-- id: ... -->` line holding the fighter's ID from `input/fighters.json`. Card names match `input/heroes.json`.

The strategy text is written from the guides listed under Further reading for that fighter. Some fighters have fewer guides, so their entries are shorter.
